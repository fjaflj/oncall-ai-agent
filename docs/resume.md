# 简历与面试说明

项目名称：OnCall AI Agent 智能运维助手（基于开源项目二次开发）

按实际参与情况表述：

- 基于 Spring Boot、Spring AI Alibaba 和 Milvus，梳理和维护文档入库、工具检索、多轮问答与多 Agent 告警诊断链路。
- 完善文件上传边界校验和索引失败反馈，避免越界写入及入库失败误报成功。
- 解耦 Mock 日志与 MCP 配置，实现演示模式和外部日志接入模式切换。
- 补充上传与工具配置回归测试及 GitHub Actions 构建流程。

不要将继承功能描述为全部从零独立开发，也不要填写未经测量的性能、准确率或降本数字。

面试前应能解释：上传成功为什么不等于索引成功；历史窗口为什么不等于会话 TTL；Prompt 重试约束为什么不等于强制终止；更换 Embedding 模型为什么涉及维度与索引迁移。
